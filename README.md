# Joshfield

> 흐릿한 문제를 선명한 화면으로. — 웹·모바일 UX/UI 디자이너 Josh의 포트폴리오

- 화면 기획서: [`docs/spec.md`](docs/spec.md)
- 작업 안내(디자인 토큰, 원칙, 진행 단계): [`CLAUDE.md`](CLAUDE.md)

## 기술 스택

Next.js 16 · TypeScript · Tailwind CSS v4 · Motion · Vercel

## 로컬에서 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 (국문), http://localhost:3000/en (영문)을 엽니다.

## 주요 명령

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 실행 (저장하면 바로 반영) |
| `npm run build` | 배포용 빌드 |
| `npm run start` | 빌드 결과 실행 |
| `npm run lint` | 코드 규칙 검사 |
